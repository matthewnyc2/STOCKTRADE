# 07 - TUTORIAL OVERVIEW

## Overview

The Tutorial section (accessed via "LEARN" from the dashboard) is where users master trading fundamentals. This isn't a boring textbook - it's an interactive academy with clear progression, practical exercises, and game-like rewards.

---

## THE EDUCATIONAL PHILOSOPHY

### Core Beliefs

1. **Learn by doing**: Every concept is followed by practice
2. **Immediate feedback**: Know if you're right instantly
3. **Progressive difficulty**: Build on what you know
4. **Multiple paths**: Visual learners, readers, and practitioners all welcome
5. **Reward mastery**: XP, unlocks, and recognition for completion

### The Two Modes (Reminder)

| Mode | Experience | Metric |
|------|------------|--------|
| **GAME MODE** | Earn virtual money for correct answers | Dollars earned |
| **PROFESSIONAL MODE** | Take tests, get scores | Percentage correct |

Same content, different skin. User can switch in settings.

## TRACK 2: CANDLESTICKS (DETAILED)

The Candlesticks track is the most important educational track. Here's the full curriculum:

### Module 2.1: What is a Candle?

**Learning Objectives:**
- Understand OHLC (Open, High, Low, Close)
- Know what body and wicks represent
- Distinguish bullish vs bearish candles

**Content:**
1. Anatomy of a candle (interactive diagram)
2. The four prices explained
3. Body size and what it means
4. Wick length and what it means
5. Color coding convention

**Exercise:**
- Given OHLC values, draw the candle
- Given a candle, identify the OHLC values

---

### Module 2.2: Reading Candle Charts

**Learning Objectives:**
- Read price movement over time
- Understand timeframes
- Identify trends visually

**Content:**
1. How candles form a chart
2. Time axis explained
3. Zooming in/out (timeframe changes)
4. Support and resistance basics
5. Trend identification

**Exercise:**
- "Is this trending up, down, or sideways?"
- "Mark the support level"

---

### Module 2.3: Single Candle Patterns

**Learning Objectives:**
- Recognize key single-candle patterns
- Understand their implications
- Know when to look for them

**Patterns Covered:**
1. Doji (indecision)
2. Hammer / Hanging Man
3. Shooting Star / Inverted Hammer
4. Marubozu (strong conviction)
5. Spinning Top

**Exercise:**
- Identify the pattern
- "What does this suggest?"

---

### Module 2.4: Two-Candle Patterns

**Learning Objectives:**
- Recognize two-candle reversal patterns
- Understand engulfing patterns
- Know continuation vs reversal

**Patterns Covered:**
1. Bullish/Bearish Engulfing
2. Piercing Line / Dark Cloud Cover
3. Tweezer Tops/Bottoms
4. Harami (inside bar)

**Exercise:**
- Spot the pattern in a chart
- Predict likely next move

---

### Module 2.5: Three+ Candle Patterns

**Learning Objectives:**
- Recognize complex patterns
- Understand pattern reliability
- Apply pattern context

**Patterns Covered:**
1. Morning Star / Evening Star
2. Three White Soldiers / Three Black Crows
3. Rising Three Methods / Falling Three Methods
4. Island Reversal

**Exercise:**
- Advanced pattern recognition
- Context-aware predictions

---

### Module 2.6: Candle Patterns in Context

**Learning Objectives:**
- Patterns at support/resistance
- Volume confirmation
- Timeframe relevance
- False signals

**Content:**
1. Where patterns appear matters
2. Volume as confirmation
3. Higher timeframe = more reliable
4. When patterns fail

**Exercise:**
- "Should you trust this pattern? Why?"

---

### Module 2.7: Advanced Candle Analysis

**Learning Objectives:**
- Candle clusters
- Price action reading
- Order flow basics

**Content:**
1. Reading groups of candles as a story
2. Rejection and acceptance
3. What candles tell us about orders
4. Combining with indicators

**Exercise:**
- Full chart analysis exercise
- Write analysis of what you see

## REWARDS AND PROGRESSION

### XP Awards

| Activity | XP Earned |
|----------|-----------|
| Complete "Learn It" section | 25 XP |
| Complete "See It" section | 25 XP |
| Pass "Play It" (minimum score) | 50 XP |
| Perfect score on "Play It" | +50 XP bonus |
| Complete "Master It" challenge | 100 XP |
| Speed bonus (complete under time) | +25% XP |
| Streak bonus (3+ modules in a row) | +10% XP |

### Unlocks

| Completion | Unlocks |
|------------|---------|
| Track 1 complete | Candlestick track |
| Module 2.1-2.2 | Basic candle understanding (quiz gate) |
| Track 2 complete | Technical Analysis track + indicators in Armory |
| Track 3 complete | Strategy track |
| All tracks complete | "Scholar" badge + Tier 5 shortcut |
