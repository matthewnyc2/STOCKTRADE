# 04 - ARMORY TIERS: DETAILED PROGRESSION

## Overview

This document specifies the exact unlocks and requirements for each of the 5 progression tiers in the Armory system.

---

## TIER 1: INITIATE

### Spirit
> *"You are nobody. Prove you understand the basics."*

### Visual Identity
- **Color**: Bronze/Copper
- **Icon**: Single sword
- **Badge**: Plain circle

### Unlocks at Tier 1

| Category | Available | Details |
|----------|-----------|---------|
| **Assets** | 3 | BTC, ETH, + 1 user choice |
| **Timeframes** | 1 | 1-hour candles only |
| **Duration** | 7 days | One week of history |
| **Indicators** | 3 | SMA, EMA, Volume |
| **Exotic** | None | Locked |

### Requirements to ENTER Tier 1
- Complete account creation
- Accept terms of service
- (Automatic - everyone starts here)

### Requirements to LEAVE Tier 1 (Advance to Tier 2)
- Complete the tutorial introduction module
- Run at least 3 backtests
- Understand what a candle is (pass quiz)

### XP Range
- 0 to 999 XP

---

## TIER 2: APPRENTICE

### Spirit
> *"You've tasted battle. Now learn to survive."*

### Visual Identity
- **Color**: Silver
- **Icon**: Crossed swords
- **Badge**: Shield outline

### Unlocks at Tier 2

| Category | Available | Details |
|----------|-----------|---------|
| **Assets** | 10 | Top 10 by market cap |
| **Timeframes** | 3 | 15m, 1h, 4h |
| **Duration** | 30 days | One month of history |
| **Indicators** | 6 | +RSI, MACD, Bollinger Bands |
| **Exotic** | None | Still locked |

### Requirements to ENTER Tier 2
- All Tier 1 exit requirements met
- 1,000+ XP accumulated

### Requirements to LEAVE Tier 2 (Advance to Tier 3)
- Run at least 10 backtests total
- At least 3 backtests must be profitable (> 0% return)
- Complete the Candles 101 tutorial module
- Pass the candlestick patterns quiz (70%+)

### XP Range
- 1,000 to 4,999 XP

---

## TIER 3: JOURNEYMAN

### Spirit
> *"You can think. Now prove you can outthink the market."*

### Visual Identity
- **Color**: Gold
- **Icon**: Sword and shield
- **Badge**: Shield with star

### Unlocks at Tier 3

| Category | Available | Details |
|----------|-----------|---------|
| **Assets** | 25 | Top 25 + popular alts |
| **Timeframes** | 5 | 15m, 1h, 4h, 1d + 5m preview |
| **Duration** | 90 days | Three months of history |
| **Indicators** | 10 | +Ichimoku, Fibonacci, ATR, OBV |
| **Exotic** | Preview | Can VIEW but not use funding rates |

### Requirements to ENTER Tier 3
- All Tier 2 exit requirements met
- 5,000+ XP accumulated

### Requirements to LEAVE Tier 3 (Advance to Tier 4)
- Create a strategy that beats HODL by 15% over a 30-day backtest
- Run at least 25 backtests total
- Complete all basic tutorial modules
- Maintain a win rate of 50%+ across last 10 backtests

### XP Range
- 5,000 to 14,999 XP

---

## TIER 4: STRATEGIST

### Spirit
> *"Profit is easy. Consistency is mastery."*

### Visual Identity
- **Color**: Platinum
- **Icon**: Double swords + shield
- **Badge**: Crowned shield

### Unlocks at Tier 4

| Category | Available | Details |
|----------|-----------|---------|
| **Assets** | 50 | Extensive list + custom requests |
| **Timeframes** | 7 | All standard + 1m (with warning) |
| **Duration** | 1 year | Twelve months of history |
| **Indicators** | 15 | +Order flow basics, Volume Profile |
| **Exotic** | Partial | Funding rates, basic on-chain |

### Requirements to ENTER Tier 4
- All Tier 3 exit requirements met
- 15,000+ XP accumulated

### Requirements to LEAVE Tier 4 (Advance to Tier 5)
- Maintain positive P&L across 20 consecutive paper trades
- Maximum drawdown under 15% across those trades
- Achieve Sharpe ratio > 1.0 on a 90-day backtest
- OR complete 4 of 7 Gauntlet challenges

### XP Range
- 15,000 to 49,999 XP

---

## TIER 5: SHADOW MASTER

### Spirit
> *"You see what others cannot. Trade in the shadows."*

### Visual Identity
- **Color**: Obsidian/Dark Purple with gold trim
- **Icon**: Crown with flames
- **Badge**: Ornate crest with M

### Unlocks at Tier 5

| Category | Available | Details |
|----------|-----------|---------|
| **Assets** | Unlimited | Any tradeable asset + custom |
| **Timeframes** | All | Including tick data (if available) |
| **Duration** | 3+ years | Maximum available history |
| **Indicators** | All | Full library + custom indicator builder |
| **Exotic** | Full | Order books, sentiment, on-chain, whale alerts, cross-exchange |

### Requirements to ENTER Tier 5
- All Tier 4 exit requirements met
- 50,000+ XP accumulated
- EITHER:
  - Achieve Sharpe ratio > 2.0 over 6-month backtest
  - OR complete "The Gauntlet" (all 7 challenges)

### Prestige Option
- At Tier 5, user can "Prestige" to reset to Tier 1
- Keeps cosmetic badge showing prestige count
- Gains permanent +5% historical depth at all tiers
- Creates replayability and achievement hunting

### XP Range
- 50,000+ (no cap)

## XP EARNING RATES

| Action | XP Earned | Notes |
|--------|-----------|-------|
| Complete a backtest | 50 XP | Regardless of result |
| Profitable backtest | +100 XP | Bonus for profit |
| Beat HODL benchmark | +200 XP | Additional bonus |
| Paper trade executed | 25 XP | Each trade |
| Profitable paper trade | +50 XP | Bonus |
| Tutorial module complete | 100-300 XP | Varies by length |
| Quiz passed | 50-150 XP | Varies by difficulty |
| Daily challenge complete | 300-750 XP | As specified |
| Gauntlet challenge complete | 1,000 XP | Per challenge |
| First of the day bonus | +25% | First activity each day |
| Streak bonus (7 days) | +50% | Multiplier on all XP |

## TIER ADVANCEMENT CELEBRATIONS

When a user advances to a new tier:

### Visual
- Full-screen overlay with tier badge
- Particle explosion / fireworks
- New tier name animates in
- List of new unlocks revealed one by one

### Audio
- Triumphant fanfare
- Coin/achievement sound
- Voice line (optional): "Welcome to [Tier Name]"

### Notification
- Push notification if enabled
- Email summary of new unlocks
- Badge appears on dashboard

## IMPLEMENTATION PROMPT FOR DEVELOPERS

```
BUILD THE TIER PROGRESSION SYSTEM

Context:
- Users progress through 5 tiers in the Armory
- Each tier unlocks more data access
- Progression is based on XP and gate completion
- This is a core system that affects entire app

Requirements:
1. Create tier configuration data structure
2. Implement XP tracking and calculation
3. Build tier advancement logic
4. Create unlock checker (what does user have access to?)
5. Design celebration modal/animation for tier-up
6. Implement prestige system for Tier 5
7. Create tier badge components

Data model:
```typescript
interface UserProgression {
  currentTier: 1 | 2 | 3 | 4 | 5
  currentXP: number
  prestigeCount: number
  unlockedAt: {
    tier2: Date | null
    tier3: Date | null
    tier4: Date | null
    tier5: Date | null
  }
}
```

Deliverables:
- TierConfig constant with all tier data
- useTierProgression hook
- TierBadge component
- TierAdvancementModal component
- XPTracker service
- UnlockChecker utility

Reference:
- See 05-armory-gates.md for gate conditions
- See 11-progression-database.md for full schema
- See 12-api-endpoints.md for API specs
```
